Beaucoup de candidats gardent un seul CV et le modifient en continu. Resultat: informations melangees, elements oublies, qualite en baisse.

La solution: un **systeme de versioning CV**.

## Opportunite mots-cles 2026

- versioning cv
- plusieurs versions de cv
- cv adapte selon le poste
- nom de fichier cv pro
- modele cv par role

## Structure en 3 couches

1. CV Maitre: tout votre historique.
2. CV Role: une version par famille de postes.
3. CV Offre: version finale pour une annonce precise.

Vous gardez le controle sans perdre d'informations.

## Regle de nommage des fichiers

Format recommande:

`nom-prenom-role-entreprise-v3.pdf`

Exemple:

`martin-claire-productmanager-miro-v3.pdf`

## Journal de modifications minimal

Pour chaque CV role, notez:

- ajouts
- suppressions
- chiffres mis a jour

En quelques semaines, vous voyez ce qui convertit le mieux.

## Routine hebdomadaire de 10 minutes

- ajouter les nouveaux resultats au CV Maitre
- synchroniser les meilleurs bullets vers CV role
- archiver les anciennes versions CV offre

## Checklist avant envoi

- titre de poste coherent
- mots-cles de l'annonce inclus
- resultats chiffres recents
- nom de fichier professionnel
- export PDF propre

Un bon CV, c'est aussi une methode.
